# Анализ асимптотической сложности

Для задачи 5 n — количество элементов массива.
Для задач 49 и 50 n — количество строк, m — количество столбцов.
Для задач 54 и 55 n — размер стороны квадратной матрицы.

Время вычислительного метода рассматривается отдельно
от времени полной программы, включающей чтение входных данных.

Дополнительная память метода указана без входного массива,
но с учётом создаваемого результата.
Общая память программы включает хранение входных данных.

| Задача | Время вычислительного метода | Дополнительная память метода | Время полной программы | Общая память программы |
|---|---|---|---|---|
| 5 | O(n) | O(1) | O(n) | O(n) |
| 49 | O(n * m) | O(n) | O(n * m) | O(n * m + n) |
| 50 | O(n * m) | O(m) | O(n * m) | O(n * m + m) |
| 54 | O(n) | O(1) | O(n²) | O(n²) |
| 55 | O(n) | O(1) | O(n²) | O(n²) |

## Задача 5

Цикл проходит примерно n / 2 элементов.
Каждая итерация выполняет постоянное количество действий.
Постоянный множитель 1/2 не влияет на порядок роста:
время вычисления равно O(n).

Метод использует только сумму и индекс: O(1) дополнительной памяти.
Полная программа хранит массив из n чисел: O(n) памяти.
Чтение массива также требует O(n) времени.

## Задача 49

Внешний цикл проходит n строк, внутренний — m столбцов.
Всего выполняется n * m сложений: O(n * m) времени.

Метод создаёт массив из n сумм: O(n) дополнительной памяти.
Полная программа хранит матрицу и результат:
O(n * m + n) памяти.

Чтение матрицы требует O(n * m), вывод сумм — O(n).
Итоговое время при положительных размерах: O(n * m).

## Задача 50

Каждый из n * m элементов посещается один раз:
O(n * m) времени вычисления.

Массив результата содержит m сумм: O(m) дополнительной памяти.
Общая память с учётом матрицы: O(n * m + m).

Чтение матрицы требует O(n * m), вывод — O(m).
Итоговое время при положительных размерах: O(n * m).

## Задача 54

Вычислительный метод посещает n элементов главной диагонали:
O(n) времени.

Используются сумма и индекс: O(1) дополнительной памяти.

Полная программа сначала читает и сохраняет n² элементов.
Поэтому её общее время равно O(n²), общая память — O(n²).

## Задача 55

Вычислительный метод посещает n элементов побочной диагонали.
Расчёт индекса n - 1 - i занимает O(1).
Итого: O(n) времени и O(1) дополнительной памяти.

Чтение и хранение всей матрицы в main требуют O(n²) времени
и O(n²) памяти. Поэтому для полной программы обе оценки — O(n²).
