## Организация программы

Каждая задача находится в отдельном пакете ru.bmstu.lab1.task_N.

Класс Main содержит метод main для ввода и вывода
и отдельный метод вычисления результата.

Исходные числа хранятся в int[] или int[][].
Эти структуры соответствуют форме входных данных
и позволяют обращаться к элементам по индексам.

Для сумм используется long, чтобы сумма нескольких значений int
не переполняла тип int.

Ввод выполняется через Scanner, вывод — через System.out.
Предполагается, что входные данные соответствуют условию задачи.

## Задача 5

Вход: количество элементов n, затем n целых чисел.

Решение: пройти по индексам 0, 2, 4 и далее с шагом 2,
прибавляя соответствующие элементы к сумме.

Используется одномерный массив int[].
Чётность относится к индексу, а не к значению элемента.

## Задача 49

Вход: количество строк n, количество столбцов m,
затем n строк по m целых чисел.

Решение: обойти все элементы матрицы двумя вложенными циклами.
Элемент matrix[i][j] прибавляется к sums[i].

Матрица хранится в int[][].
Результат хранится в long[] длины n.
Суммы выводятся через пробел в порядке строк.

## Задача 50

Формат входа совпадает с задачей 49.

Решение: обойти все элементы матрицы.
Элемент matrix[i][j] прибавляется к sums[j].

Результат хранится в long[] длины m.
Суммы выводятся через пробел в порядке столбцов.

## Задача 54

Вход: размер n, затем n строк квадратной матрицы,
каждая из которых содержит n целых чисел.

У элементов главной диагонали совпадают индексы строки и столбца.
Решение складывает matrix[i][i] для i от 0 до n - 1.

## Задача 55

Формат входа совпадает с задачей 54.

У элементов побочной диагонали сумма индексов равна n - 1.
Решение складывает matrix[i][n - 1 - i]
для i от 0 до n - 1.

## Автоматические тесты

Для каждой задачи предусмотрено по 7 тестов JUnit:
всего 35 тестов.

Проверяются обычные входные данные, нули, отрицательные числа,
особенности размеров и суммы, превышающие диапазон int.

Для диагоналей предусмотрены проверки, позволяющие отличить
главную диагональ от побочной и исключить элементы вне диагонали.

Для каждой задачи отдельно проверяется работа main:
чтение входных данных и точный текст результата.
После такой проверки стандартные потоки восстанавливаются.
